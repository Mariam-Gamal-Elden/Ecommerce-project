
# E-commerce Web Application

This is an e-commerce web application built using React. Users can browse through products, view product details, and interact with various features of the site. The application includes a login system and product catalog.

## Features

1. **User Authentication**:
   - Users can **sign up** and **log in** to access the main page of the app.
   - Authentication is required to view the products and interact with other features.
   - If the user is not logged in, they will be redirected to the login page.

2. **Product Catalog**:
   - After successful login, users will be directed to the **home page**, which displays a list of products.
   - The **product catalog** is fetched from an API and displayed as a grid with product names, prices, and images.

3. **Product Details**:
   - Clicking on a product from the catalog will show detailed information about that product, such as description, price. You can either:
- Hover over the product and click the **eye icon** to view more details, or
- Click on the product's title to navigate to the product details page.

## Prerequisites
Before you begin, make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- [Git](https://git-scm.com/) (To clone the repository)

## Installation

### Step 1: Clone the Repository

To get started, you first need to clone the repository to your local machine.


```bash
  git clone https://github.com/Mariam-Gamal-Elden/Ecommerce-project.git
```
### Step 2: Navigate to the Project Directory

```bash
  cd Ecommerce-project
```
### Step 3: Open the Project in VS Code
You can open the project in VS Code by running the following command in your terminal:

```bash
  code . 
```

### Step 4: Install Dependencies:
In the VS Code terminal, run the following command to install the required dependencies:

```bash
  npm install 
```
### Step 5: Run the Application:
```bash
  npm start
```
### Step 6: View the Application
Open your browser and go to http://localhost:3000 to see the app in action.
